#参数校验
接口文档中会对请求变量进行备注要求，需要对输入的请求参数进行校验。
spring提供了validation校验框架。（以 注解@方式）
    1.引入依赖；
    2.在需要校验的变量前面（方法参数里）添加@Pattern，并使用正则表达式；
    3.在controller前添加@Validated起作用。
