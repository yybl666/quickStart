    3.在controller前添加@Validated起作用。

# 登录令牌
不加令牌，在没有登录的情况下就可以得到私有文章数据是不合适的。
令牌过程--login后得到令牌给浏览器，在后续的请求中浏览器会带上这个令牌，然后服务器会解密这个令牌是否符合。
## 要求
    1.令牌里需要有基础的用户数据，以减少对数据库的访问；
    2.令牌是不可随意破解的----jwt
## 令牌---一个字符串
    1.头部（签名算法，令牌类型）+ 有效载荷（base64编码，不安全的不可以放私密） + 加密密钥

引入依赖，测试。
